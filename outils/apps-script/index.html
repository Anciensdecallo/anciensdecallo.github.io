Activer l'envoi réel des formulaires

Les Anciens de Callo · Lycée Marcel Callo & Pôle Sup Callo

Le site est hébergé sur GitHub Pages : il est statique, il ne peut pas envoyer de courriel lui-même. Les formulaires passent donc par un petit script Google (Google Apps Script), hébergé gratuitement sur le compte Google de l'école.

Les deux fichiers

Voir le script à copier (Code.txt) Procédure complète (INSTALLATION.md)

Code.txt s'affiche directement dans le navigateur : sélectionnez tout (Ctrl+A) puis copiez (Ctrl+C). Le fichier Code.gs sert de référence technique et se télécharge.

Où en sont les formulaires

Sans installationLe message s'ouvre dans la messagerie du visiteur, déjà adressé et rédigé. Il ne lui reste qu'à cliquer « Envoyer ».
Avec installationL'envoi devient automatique et silencieux pour le visiteur.

Les 3 étapes indispensables

  1. Créer le projet sur script.google.com, coller tout le contenu de Code.txt dans Code.gs, puis Ctrl+S.
  2. Lancer la fonction testEnvoi : un courriel de test doit arriver aux deux adresses.
  3. Créer une Application web : Exécuter en tant que : Moi · Qui a accès : Tout le monde.

Piège n°1 — republier l'ancien code. Modifier le script ne suffit pas : il faut publier une nouvelle version du déploiement, sinon Google continue d'exécuter la version figée. Déployer → Gérer les déploiements → ✏️ → Version : « Nouvelle version » → Déployer.

Piège n°2 — le mauvais réglage d'accès. Trois choix existent : Moi uniquement, Tout le monde avec un compte Google (exige quand même une connexion), et Tout le monde (sans mention de compte) : c'est le seul qui rend le formulaire utilisable par un visiteur non connecté.

Vérifier l'adresse sans être connecté

Ouvrir l'URL du déploiement terminée par /exec en navigation privée. Elle doit répondre :

{"ok":true,"service":"Les Anciens de Callo","heure":"…"}

Si à la place s'affiche une page « Connexion – Comptes Google », le réglage « Qui a accès » n'est pas sur Tout le monde (piège n°2).

Utilitaires du script

  • testEnvoi() — à lancer depuis l'éditeur : envoie un courriel de test aux deux adresses et indique le quota restant.
  • construireKpi() — crée la feuille « KPI » (visites, inscriptions et taux de conversion par origine de campagne).
  • …/exec?action=config — renvoie les destinataires réellement actifs dans le déploiement en cours (permet de vérifier à distance que la bonne version est publiée).
